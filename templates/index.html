ABOUT THE PROJECT

Python Q&A Chatbot

This project is an educational Python question-and-answer chatbot developed using Flask, Python and Natural Language Processing techniques. It uses TF-IDF vectorization and Cosine Similarity to find relevant answers from a predefined Python knowledge base.

The chatbot is designed to answer Python-related questions rather than acting as a general-purpose AI chatbot.
